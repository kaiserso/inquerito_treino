This R Studio Project contains code and publicly-available demo data from NHANES for a practical training session on basic R usage for those not familiar with R or R Studio. It is part of a sequence of modules on practical survey data analysis with R prepared by CDC for INS staff.  Currently four modules are included, a base R primer written as an R script, and three Shiny apps that are provide online tutorials for base R and tidy R. The tidy R apps are currently deployed at peteryoung.shinyapps.io/tutorial-base-R/.   

Note: Code comments and text are in Portuguese.

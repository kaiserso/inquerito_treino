O que é o tidyverse?

O tidyverse é um conjunto de pacotes do R que compartilham uma filosofia comum de desenho, gramática e dados. Ele é projetado para tornar a análise de dados mais intuitiva e eficiente. Os pacotes mais comuns incluem:

  • dplyr: Manipulação de dados (filtragem, ordenação, resumo, etc.)
  • ggplot2: Visualização de dados
  • tidyr: Transformação de dados (por exemplo, de formato largo para longo)
  • tibble: Uma versão moderna de data frames
  • haven: Leitura e escrita de dados em formatos como SPSS, Stata, etc.

entre outros.

O que é o tidy R?

O tidy R é uma abordagem para trabalhar com dados no R que enfatiza a clareza e a simplicidade. Ele se baseia nos princípios do tidyverse, mas pode ser usado com qualquer pacote ou função do R. A ideia é que os dados sejam organizados de forma que cada variável seja uma coluna, cada observação seja uma linha e cada tipo de unidade de observação seja uma tabela.

O que é um tibble?

Um tibble é uma versão moderna de um data frame no R. Ele é parte do tidyverse e oferece várias vantagens sobre os data frames tradicionais: * Impressão mais limpa: Tibbles exibem apenas as primeiras linhas e colunas, evitando a sobrecarga visual. * Tipos de dados explícitos: Tibbles mantêm os tipos de dados de forma mais explícita, o que ajuda a evitar erros. * Subconjunto seguro: Tibbles não permitem a subconfiguração de colunas que não existem, o que ajuda a evitar erros comuns.

O que é um pipe (tubo)?

Um pipe (tubo) é um operador |> ou %>% que permite encadear várias operações de forma sequencial. Ele é usado para passar o resultado de uma operação como entrada para a próxima, tornando o código mais legível e intuitivo. Por exemplo:

library(dplyr)
mtcars |>
  filter(mpg > 20) |>
  select(mpg, cyl, hp) |>
  arrange(desc(mpg))

O pipe define uma cadeia de operações sequenciais que é mais facilmente descrita em lingua natural, por exemplo, “pegue na tabela mtcars, filtar para somente incluir as linhas onde os mpg sejam acima de 20, selecciona as variáveis mpg, cyl e hp, e por em ordem decrescente segundo os mpg.” Compare isto com a versão em base R do mesmo código:

(mtcars[mtcars$mpg > 20, c("mpg", "cyl", "hp")])[order(mtcars$mpg[mtcars$mpg > 20], decreasing = TRUE), ]

Pode ver que o código com pipes é mais linear, mais legível e fácil de seguir.

Agrupar

Agora vamos aprender como calcular estatísticas sobre dados agrupados. Podemos usar group_by para criar grupos nos dados:

mtcars |> group_by(cyl)

Notou a linha # Groups: cyl [3]? Isto indica que os dados agora são agrupados, embora o agrupamento somente tem valor prático quando usamos num comando subsequente:

mtcars |> group_by(cyl) |> summarize(mpg_media = mean(mpg))

O resultado é um tibble com a media de mpg para cada grupo. Os resultados incluem as variáveis de agrupamento, junto com as novas variáveis criadas pelos comandos que aparecem no summarize.

Podemos fazer mais de que um comando ao mesmo tempo, e podemos criar grupos sobre combinações de variáveis, por exemplo o mpg (kilometragem) media e o número de observações para cda combinação de gear e cyl:

mtcars |> group_by(gear, cyl) |> summarize(mpg_media = mean(mpg), n = n())
## `summarise()` has grouped output by 'gear'. You can override using the
## `.groups` argument.
